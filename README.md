## ✦ Key Interactive Components

1. **Editorial Hero & Depth Masking:** Dynamic typography (`clamp` / `vw`), high-contrast portrait mask, and live discipline switcher.
2. **`ScrollExpandMedia` Kinetic Canvas:** Scroll-driven media expansion stage that smoothly interpolates card dimensions, aspect ratio, and blur filters at 120 FPS.
3. **Horizontal Spatial Experience Canvas:** Sticky timeline translating vertical scroll into horizontal spatial progression through academic and technical journey chapters.
4. **FlexCarousel (OGL WebGL Liquid Shader):** Interactive curved card slider powered by OGL with real-time mesh displacement and focus-on-click modals.
5. **WorksWheel 3D Drum Reel:** Mathematical 3D cylindrical drum projection with momentum drag gestures, wheel scroll, and step navigation.
6. **Areas of Focus Accordion:** Interactive technical domain showcases detailing Core Java, Applied AI/ML, and Full-Stack Engineering capabilities.
7. **Interactive Project Inspection Modal:** Detail modal with verified tech stack badges, system highlights, and direct repository links.

## ✦ Getting Started Locally

This project is built using native ES modules and standard web technologies. You can run it with any local static HTTP server:

### Option 1: Python HTTP Server (Recommended)
```bash
# In the ECHO-WEBSITE directory:
python -m http.server 8080
```
Then open `http://localhost:8080` in your web browser.

### Option 2: Node.js / npx serve
```bash
npx -y serve .
```
